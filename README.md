# 2025_copepods

Workflow to reproduce Lagrangian dispersal simulations to assess connectivity between copopod populations in the Baltic Sea & North Sea. Scripts include particle dispersal, connectivity analysis and figure production.

**Hydrodynamic model**: BSH-HBMnoku https://www.bsh.de/DE/THEMEN/Modelle/Hydrodynamik/hydrodynamik_node.html

**Lagrangian particle dispersal toolbox**: OceanParcels https://www.oceanparcels.org/
